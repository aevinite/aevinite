# Aevinite

**We help businesses grow.** Aevinite is a company based in **Ahmedabad, Gujarat, India**. Rishi Nakrani (Founder) and Jenish Patel (Co-Founder) started it on **28 July 2024** under the name *Infinite*, and renamed it **Aevinite** on 16 June 2026.

We look at how a business runs today, find what slows it down, and put the right websites, software and automation in place so it can grow.

## Aevidine — our own product for restaurants

**[Aevidine](https://www.aevinite.com/aevidine)** is restaurant management software made by Aevinite in Ahmedabad:

- **QR code ordering:** guests scan the code on their table and order from their phone, no app to install
- **Kitchen screen and KOT printing:** every order reaches the kitchen the moment it is placed
- **Waiter tablet, manager panel and owner reports:** tables, bills, GST invoices and daily sales
- **Works offline:** orders are kept and sent when the internet comes back

## The name

*Aevinite* comes from **Aevum**, a dimension of existence with a beginning but no end, and echoes **Infinite**, the company's original name: *the beginning with no end.*
